Production Output Formats

Structured formats proven to maximize retrieval and reasoning accuracy in modern frontier models.

1. Anthropic Prompt XML

Recommended by Anthropic for Claude 3.5 Sonnet and Opus. Segregates files into indexed <document> wrappers with CDATA protection.

<documents>

├── src/
│   └── index.js
</directory_tree>

</documents>

Exposed MCP Tools

  • pack_codebase Pack directory trees with token caps, git diffs, and formatting options into ready context.
  • get_tree Generate visual directory hierarchies with file sizes and token estimates.
  • pack_diff Extract and pack staged or branch Git diffs with affected file context.
  • estimate_tokens Fast BPE token approximation for any arbitrary text snippet or disk file.

Automate in GitHub Actions

Generate packed codebase contexts inside your CI/CD workflows for automated PR review or documentation steps.

.github/workflows/ai-review.yml
- name: Pack Repository Context
  uses: fastpresspages/contextpack@main
  id: pack
  with:
    path: '.'
    format: 'xml'
    max-tokens: '64k'
    with-tree: 'true'
    git-diff: 'true'
    out: 'context.xml'

- name: AI Review Step
  run: |
    echo "Packed ${{ steps.pack.outputs.files }} files (${{ steps.pack.outputs.tokens }} tokens)"
    # Pass context.xml to your LLM API call

Frequently Asked Questions

Straightforward answers about licensing, token algorithms, and security.

Is ContextPack really free?

Yes, 100% free and open-source under the Apache-2.0 license. There are no paid tiers, no API keys, and no telemetry.

How accurate is the token estimator?

ContextPack's tokenizer uses a calibrated heuristic calibrated against Claude and cl100k_base models. In benchmark testing on real codebases (JavaScript, TypeScript, Python, Go, Rust), it correlates within ~3-5% of true tokenizers while executing orders of magnitude faster without large WASM/Rust binary dependencies.

How does token budgeting handle large codebases?

When you set --max-tokens, ContextPack reserves tokens for header metadata and the directory tree, packs files until the budget ceiling is approached, and cleanly tracks omitted files in an <omitted_files> block so your model knows which files were skipped.

Does ContextPack send any code over the internet?

Never. All file operations, tree generations, token counts, and diffs are computed locally in your Node.js process.

Who maintains ContextPack?

ContextPack is developed and maintained by FastPress Labs (github.com/fastpresspages), an open-source studio committed to building zero-bloat developer tools.
