Privacy Policy

Effective Date: October 26, 2026

1. Summary

ContextPack is built on strict data privacy principles. The CLI tool, Node.js library, and Model Context Protocol (MCP) server run 100% locally on your machine. We do not collect telemetry, analytics, code samples, or token usage metrics.

2. What the Website Collects

This static website is hosted on GitHub Pages. We do not set cookies, use session replay, or run tracking scripts. Standard HTTP access logs are maintained by GitHub in accordance with their privacy policy.

3. The Feedback Form

If you choose to submit feedback or feature requests via our contact form, your email address and message are delivered to meetcode99@gmail.com via FormSubmit. This information is used strictly to reply to your inquiry and is never sold, shared, or added to marketing newsletters.

4. Code Privacy in ContextPack CLI and MCP

When running contextpack or contextpack-mcp, all file reading, token estimations, and diff packaging occur entirely inside your local runtime. No source code or prompts leave your machine.
