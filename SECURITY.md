# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

ContextPack processes local codebase files and operates as an MCP server. Security matters:
- ContextPack does not transmit code or diffs to remote servers.
- When running in MCP mode, file reading is restricted to requested local paths.

If you discover a security issue or vulnerability:
1. Please email **meetcode99@gmail.com** with the subject `[ContextPack Security Vulnerability]`.
2. Provide details, steps to reproduce, and potential impact.
3. We will acknowledge receipt within 24 hours and coordinate a fix release promptly.
